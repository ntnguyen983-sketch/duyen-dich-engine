# Duyên Dịch v3.1 UI Test

Mở `ui_test/index.html` qua một static server có cùng origin với API.

Form test toàn bộ input hiện tại: question, number, time, GPS, address, image.

UI kiểm tra response: L1-L6, canonical S07 vocabulary, contract version, input hash, confidence firewall, GPS/image acceptance và hiển thị canonical JSON.

API endpoint mặc định: `/api/v31`.
