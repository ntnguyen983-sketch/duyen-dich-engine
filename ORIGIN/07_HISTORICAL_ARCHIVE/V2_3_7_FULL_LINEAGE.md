## Kernel
Quẻ không luận sự việc. Quẻ chỉ định vị trạng thái. Đối tượng luận là Actor tại giao điểm Thiên–Địa–Nhân của Snapshot; engine đọc khuynh hướng vận động của Actor trong Dòng.

## 7-layer architecture
Layer 0 Universe → Layer 1 Coordinate → Layer 2 Object → Layer 3 Relation → Layer 4 Dynamic Engine → Layer 5 Evaluation → Layer 6 Interpretation.

Five ordering principles:
1. Có hệ quy chiếu trước.
2. Có định vị sau.
3. Có quan hệ.
4. Có động lực rồi mới đánh giá.
5. Có đánh giá rồi mới diễn giải.

## Constitution / axioms
Non-deterministic reflection; dynamic impermanence; recursive non-self; absolute traceability; conditional validity.
A0–A12 include binary primitive, existence E∈[0,1], monotone decay without new input, semantic independence of Qi, traceability, empirical treatment of unsupported weights, kernel-only state transition, observer coupling, reconstruction uncertainty σ, model separation, Actor Localization, Duyên interaction, and phase-reference coordinate.

## State representation
V_khi = [S,D,I,F,T].
Phase coordinate φ ∈ S¹ uses the twelve Trường Sinh phases and determines the direction of dV/dt.
Node schema includes Identity_ID, State_Vector, Phase_Coord, Node_Element_Matrix, Node_Qi_State, Relation_Edges, Momentum_Value, History_Log.

## Relation operators
XUNG: kinetic/phase bifurcation; HỢP: anchor binding; HẠI: dissipative loss and delay; HÌNH: vector neutralization/internal strain.
Response function: ΔS = R(S,Oij) → (ΔF, ΔT, ΔI, ΔAnchor, Δt).
Trajectory integration: S(t+1)=Φ(S(t),ΔS).

## Energy phases
Ẩn/Tích lực → Khai lực when F≥M_t → Dẫn lực when I≥0.75.

## Evaluation
S07 maps V_khi to six states: Dưỡng, Hy, Ân, Nhiễu, Tà, Sát. Uncertainty σ is explicitly reported.
Interpretation is downstream of evaluation; it must not mutate the simulation core.

## Runtime report
Snapshot → state vector / phase → state spaces M → interaction operators → ΔS → trajectory Φ → S07 → actionable strategy.
