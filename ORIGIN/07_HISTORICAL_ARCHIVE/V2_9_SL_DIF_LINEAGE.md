# DUYÊN DỊCH v2.9 SL-DIF — LINEAGE CAPTURE

Source: `V2.9.pdf` (Library source captured 2026-08-21).

## Paradigm shift
v2.9 models the six lines as a Dynamic Coupled System over an Observed Conditions Graph (OCG), computed through Six-Line Dynamic Interaction Field (SL-DIF). The analysis unit is the interaction state of the condition network at a defined Snapshot, not an isolated moving line.

Quẻ ≠ Future; Quẻ = Snapshot(t0).
Reality(t) is not identical to deterministic output. Determinism applies only to computation over the same snapshot, fixed parameters and fixed kernel.

## Core rules
Snapshot Realism, Dynamic Impermanence, semantic isolation, forward-only/no-write-back, and separation between reality, snapshot and inference.

## Historical significance
This checkpoint makes the transition from "single moving line forecasting" toward a coupled six-line dynamic system explicit. It is retained independently from later 2.9.0 reconciliation and v2.9.2 merge.
