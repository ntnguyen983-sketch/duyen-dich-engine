# 05 — IMPLEMENTATIONS

Ngăn này dành cho **công nhân**.

## Phân loại

- Reference Python
- Production Engine (Rust/C++/Go...)
- API adapter
- Web/UI
- Gemini/LLM adapter
- Quẻ/hào adapter
- Data ingestion
- Validation runner

## Luật

Implementation được phép thay đổi, tối ưu, viết lại hoặc thay thế.

Implementation **không được tự sửa Origin**. Nếu phát hiện mâu thuẫn hoặc thiếu định nghĩa, tạo issue/change proposal hoặc cập nhật research/calibration theo đúng quy trình.

## Hiện trạng repository

Runtime v3.1 hiện tại vẫn được giữ ở cây cũ để không phá production integration. Nhánh Origin này chỉ tổ chức lại nguồn mẹ và không tự ý thay thế runtime đang chạy.
